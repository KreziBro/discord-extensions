Быстрая и легкая модификация десктопного клиента Discord со встроенным набором популярных инструментов, коллекцией тем оформления, аппаратным ускорением GPU и аутентичным темным интерфейсом.

Клиент работает плавно, без просадок производительности, лишних рекламных баннеров и скрытого сбора фоновой аналитики.

## Возможности

### 🎨 Темы оформления
* AMOLED Black: чистый глубокий черный фон для OLED дисплеев
* Dracula: знаменитая фиолетовая контрастная тема
* Catppuccin Mocha: мягкие пастельные оттенки для комфортного чтения
* Nord: арктическая холодная синяя палитра
* Редактор Custom CSS: мгновенное применение собственных стилей оформления прямо из менеджера настроек

### 💬 Чат и приватность
* Silent Typing: скрытный ввод текста, никто не видит статус набора сообщения
* Message Logger: сохранение удаленных сообщений с пометкой прямо в ленте чата
* Auto Translator: кнопка мгновенного перевода любого иностранного сообщения в один клик
* Nitro Cleaner: скрытие витрины Nitro, вкладки Магазина и кнопок подарков в чате

### 🎵 Звук и мультимедиа
* Volume Booster: расширение максимальной громкости пользователей до 400% вместо стандартных 200%
* Spotify Controls: компактный плеер в панели профиля с кнопками переключения треков
* Spotify Pause Bypass: предотвращение автоматической паузы музыки при долгой голосовой связи
* Open In App: автоматическое открытие ссылок YouTube, Spotify и Steam в приложениях на ПК

### 🖥️ Интерфейс и оптимизация
* Platform Indicators: показ значка мобильного устройства рядом с именем друга в списке
* Server Grid: удобная сетка серверов в две колонки
* Без кнопок в оверлее: интерфейс модификации работает строго в основном окне и не перекрывает ваши игры
* Аппаратное ускорение GPU: плавная анимация интерфейса за счет видеокарты без нагрузки на процессор
* Блокировка аналитики: отключение фоновой отправки метрик sentry и datadoghq для снижения задержек сети
* Менеджер дополнений: удобная панель настроек в фирменном дизайне Discord по нажатию Ctrl + Shift + E
* Поддержка Chrome расширений: возможность загрузки сторонних веб дополнений прямо в клиент
* Двуязычный интерфейс: автоопределение русского или английского языка под вашу систему
* Автоматические обновления: клиент проверяет новые версии на GitHub и обновляет файлы в один клик

## Безопасность

* 100% безопасно: модификация работает локально в файлах клиента AppData
* Без инъекций в память: проект не использует сторонние DLL инжекторы
* Легкое и чистое удаление в один клик без повреждения файлов Discord

## Установка

1. Скачайте архив репозитория через кнопку Code ➔ Download ZIP и распакуйте
2. Полностью закройте клиент Discord
3. Запустите install.bat (или правой кнопкой мыши по install.ps1 ➔ Выполнить с помощью PowerShell)
4. Скрипт сохранит резервную копию, внедрит загрузчик и запустит обновленный клиент

## Горячие клавиши

* Ctrl + Shift + E: открыть панель настроек Discord Extensions
* F12: открыть консоль разработчика DevTools

## Автообновление

При запуске клиент проверяет файл version.json на GitHub. Когда выходит новая версия, прямо в окне настроек появляется уведомление. Нажмите кнопку обновления, и файлы обновятся автоматически с перезапуском клиента.

## Удаление

Чтобы вернуть клиент к заводскому состоянию:
1. Запустите uninstall.bat
2. Скрипт восстановит оригинальный index.js из резервной копии и удалит модули расширений
